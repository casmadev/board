React whiteboard · DOM + CSS · zero runtime deps

@casmadev/board

A whiteboard component built with DOM + CSS — no <canvas>. Sticky notes with a handwritten font and a subtle 3D tilt, infinite pan & zoom, 8 shipped locales (including RTL), and full TypeScript types.

$ npm install @casmadev/board
Open the Sandbox Live, interactive demos API Reference Every prop, hook & type

DOM, not canvas

Every shape is a real, inspectable, accessible DOM node. Style it with CSS variables; no draw loop to fight.

Composable by default

Swap the toolbar, context menu, or the sticky note itself. Seven overlay slots and a useCasmaBoard() hook.

Typed & tree-shakeable

Full TypeScript types, per-locale subpath exports, and zero runtime dependencies. Ships ESM + CJS.

Quick start

import { CasmaBoard } from '@casmadev/board';
import '@casmadev/board/styles.css';

export default function App() {
  return <CasmaBoard />;
}
